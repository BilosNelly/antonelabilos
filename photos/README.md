# Photos

Drop these files into this folder (`public/photos/`). The About page shows a
labelled placeholder for any that are missing, so the layout never breaks.

| File | Where it shows | Notes |
| --- | --- | --- |
| `antonela-glasses.png` | About — intro | Portrait with black glasses (transparent PNG is fine) |
| `antonela-networking.jpg` | About — intro | Expedia partner event, white blouse |
| `antonela-sushi.jpg` | About — Off the clock | Eating sushi at the outdoor table |
| `antonela-restaurant.jpg` | About — Off the clock | Dinner, spreading something on bread |
| `antonela-baby-cake.jpg` | About — Off the clock | Baby in a red dress next to a cake |

Any web format works (`.jpg`, `.png`, `.webp`). If you use a different
extension, update the paths in `src/content.ts` (`photos` object).

The hero background photo stays at `public/antonela-portrait.png`.
